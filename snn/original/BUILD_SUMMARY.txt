CORE ARCHITECTURE
─────────────────────────────────────────────────────────────────────────────

Single Network, Two Phases:

  Phase 1 (60-70% Realistic)              Phase 2 (75-85% Realistic)
  ──────────────────────────              ───────────────────────────
  • Izhikevich neurons                   • Compartmental neurons
  • PSC filtering                        • Dendritic integration
  • Refractory period                    • Backpropagating APs
  • E/I neuron types                     • Short-term plasticity
  • Homeostatic plasticity               • Structural plasticity
  • STDP learning                        • Eligibility traces
  
  Toggle: net.enablePhase2(false)        Toggle: net.enablePhase2(true)
  Speed: 2-3x slower than LIF            Speed: 5-10x slower than LIF
  Use: General research                  Use: Advanced research

FEATURE TOGGLES (Anytime)
─────────────────────────────────────────────────────────────────────────────

  net.enablePhase2(bool)           - Dendritic compartments
  net.enablePSC(bool)              - Post-synaptic current filtering
  net.enableRefractory(bool)       - Refractory period
  net.enableHomeostasis(bool)      - Homeostatic plasticity
  net.enableLearning(bool)         - STDP learning
  net.enableRewardModulation(bool) - Eligibility traces (Phase 2)

Perfect for ablation studies and experimentation.

NEURON TYPES (4 Built-in)
─────────────────────────────────────────────────────────────────────────────

  1. REGULAR_SPIKING   - Pyramidal cells (excitatory)
  2. FAST_SPIKING      - GABAergic interneurons (inhibitory)
  3. BURSTING          - Intrinsically bursting neurons
  4. DOPAMINERGIC      - Dopamine neurons (slow, modulatory)

Each has distinct spiking patterns and refractory dynamics.

LEARNING MECHANISMS
─────────────────────────────────────────────────────────────────────────────

  Phase 1:
    • STDP (Spike-Timing-Dependent Plasticity)
    • Homeostatic plasticity (maintains stable firing rate)

  Phase 2 (all of Phase 1 plus):
    • Short-term facilitation & depression
    • Structural plasticity (synapses grow/prune)
    • Eligibility traces for reward-modulated learning
    • Nonlinear dendritic integration

STIMULATION MODES
─────────────────────────────────────────────────────────────────────────────

  Phase 1:
    net.stimulate(neuron_id, current)

  Phase 2 (all of Phase 1 plus):
    net.stimulateApical(neuron_id, current)
    net.stimulateBasal(neuron_id, current)

  Allows compartment-specific input in dendritic model.

EXAMPLE USAGE
─────────────────────────────────────────────────────────────────────────────

  #include "network_unified.hpp"
  
  int main() {
      UnifiedNetwork net(20);
      
      // Choose phase
      net.enablePhase2(false);  // Phase 1: fast
      // net.enablePhase2(true); // Phase 2: advanced
      
      // Build network
      net.addNeuron(0, NeuronType::REGULAR_SPIKING);
      net.addNeuron(1, NeuronType::FAST_SPIKING);
      net.connect(0, 1, 0.2f);
      
      // Simulate
      net.stimulate(0, 5.0f);
      net.run(100);
      
      // Monitor
      std::cout << "Avg firing: " << (net.getAverageFiringRate()*100) << "%\n";
  }

  Compile: g++ -std=c++17 -O3 demo_unified.cpp

API SUMMARY
─────────────────────────────────────────────────────────────────────────────

  Configuration:
    addNeuron(id, type)                    - Add neuron of given type
    connect(pre, post, weight)             - Create synapse
    setSynapseWeight(pre, post, weight)    - Modify synapse

  Stimulation:
    stimulate(neuron_id, current)          - Direct input
    stimulateApical(neuron_id, current)    - To apical dendrite (Phase 2)
    stimulateBasal(neuron_id, current)     - To basal dendrite (Phase 2)

  Simulation:
    step()                                 - One timestep
    run(num_steps)                         - Multiple steps
    reset()                                - Clear state

  Monitoring:
    getNeuronVoltage(id)                   - Soma voltage
    getNeuronApicalVoltage(id)             - Apical dendrite (Phase 2)
    getNeuronBasalVoltage(id)              - Basal dendrite (Phase 2)
    getNeuronSpiked(id)                    - Did neuron spike?
    getSynapseWeight(pre, post)            - Synaptic strength
    getAverageFiringRate()                 - Network activity estimate
    isPhase2Enabled()                      - Check current mode
