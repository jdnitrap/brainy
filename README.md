# brainy
Brainy repository

- [snn/](snn/) — unified spiking neural network (Izhikevich neurons, STDP,
  reward, homeostasis, dendrites, short-term and structural plasticity),
  header-only C++17 with a demo and 57 pass/fail tests.
- [experiments/mnist/](experiments/mnist/REPORT.md) — brainy trained on MNIST
  handwritten digits with unsupervised STDP: 70% (100 neurons) and 76%
  (400 neurons), with analysis of where the accuracy is lost.
